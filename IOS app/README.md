## ⚡ iOS Setup & Pre-requisites

1. **Expo iOS Build (Pre-built)**:
   ```bash
   cd ../mobile-app
   npx expo run:ios
   ```
2. **Native Xcode Project**:
   - Xcode 15+
   - CocoaPods / Swift Package Manager
   - iOS 16.0+ SDK target
