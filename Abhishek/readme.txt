ABHISHEK FOLDER DIRECTORY INDEX


1. OVERVIEW

This folder contains all custom documentation code and implementation plans.
Every file created inside this folder will strictly be a plain text file ending with dot txt extension.


2. DIRECTORY STRUCTURE AND SUBFOLDERS

Folder Backend contains plain text specifications for the Node.js Express server.
Folder web frontend contains plain text specifications for the web dashboard portal.
Folder mobile app contains plain text specifications for the cross platform Expo mobile app.
Folder Ios app contains plain text specifications for native iOS SwiftUI integration.
File implementation-plan.txt contains the initial backend implementation plan.
File master-project-implementation-plan.txt contains the complete end-to-end master implementation plan.
File how-to-start-entire-project.txt contains step-by-step startup instructions for all project modules.
