STEP BY STEP NATIVE SWIFTUI IOS APPLICATION IMPLEMENTATION PLAN


1. STAGE ONE AUTHENTICATION AND SECURITY SYSTEM

Create LoginView.swift with email and password input fields.
Create OTPVerificationView.swift for six digit verification codes.
Create KeychainService.swift using Security framework for JWT tokens.
Connect AuthViewModel to POST /api/auth/login endpoint on Express backend.
Store access token securely in iOS Keychain upon successful login.


2. STAGE TWO NAVIGATION AND BASE LAYOUT

Create MainTabView.swift with bottom tab bar navigation.
Tab 1 connects to TaskListView.swift for task management.
Tab 2 connects to AttendanceClockView.swift for clock in and out.
Tab 3 connects to DirectChatView.swift for team messages.
Tab 4 connects to RAGChatbotView.swift for Gemini AI document Q and A.
Tab 5 connects to ProfileView.swift for user profile and logout.


3. STAGE THREE TASK MANAGEMENT AND AUDIT LOGS

Create TaskItem.swift Swift struct matching Task.ts schema.
Create TaskListView.swift with segmented status picker.
Create TaskCardView.swift displaying title priority color and due date.
Create TaskDetailView.swift with subtask checkboxes and attachment preview.
Connect TaskViewModel to GET /api/tasks and PUT /api/tasks/:id endpoints.
Updating task status triggers immutable TaskAuditLog entry on backend.


4. STAGE FOUR GEOLOCATION ATTENDANCE CLOCK IN OUT

Create LocationManager.swift using CoreLocation framework.
Request NSLocationWhenInUseUsageDescription permission in Info.plist.
Create AttendanceClockView.swift with animated Punch In and Punch Out button.
Display live working shift timer duration counter.
Send latitude and longitude payload to POST /api/attendance/check-in endpoint.


5. STAGE FIVE REAL TIME SOCKET IO CHAT SYSTEM

Install SocketIO-Client-Swift package in Xcode project.
Create SocketManager.swift to connect to Express backend socket server.
Pass JWT token during socket handshake for authentication.
Create DirectChatView.swift with ScrollViewReader and LazyVStack.
Listen for 'message:sent' socket event to append incoming messages live.


6. STAGE SIX GOOGLE GEMINI AI RAG DOCUMENT ASSISTANT

Create RAGChatbotView.swift with conversational search interface.
Connect RAGViewModel to POST /api/rag/query endpoint.
Create DocumentPicker sheet to upload PDF files to backend RAG engine.
Display contextual answers generated by Google Gemini AI.


7. STAGE SEVEN TESTING AND DEPLOYMENT

Test app on Xcode iOS Simulator for iPhone 15 Pro and iPhone 16 Pro.
Verify JWT authorization token attachment on all REST headers.
Verify CoreLocation permissions and geolocation capture on device.
Verify real time Socket.IO message delivery across web and mobile.
Package app for TestFlight and Apple App Store deployment.
