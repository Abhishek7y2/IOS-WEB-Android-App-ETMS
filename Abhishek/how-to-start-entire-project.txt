================================================================================
          MASTER GUIDE: HOW TO START & RUN THE ENTIRE PROJECT
================================================================================

1. STEP ONE - START THE NODE.JS BACKEND API SERVER
--------------------------------------------------------------------------------
Command sequence:
cd backend
npm install
npm run dev

Details:
- Open terminal and navigate to the backend folder.
- Run npm install to install all Node.js Express dependencies.
- Ensure backend/.env contains your MongoDB Atlas URI and PORT=5000.
- Run npm run dev to start the backend API and Socket.IO server.
- Server will launch at: http://localhost:5000 (API at http://localhost:5000/api).


2. STEP TWO - START THE NEXT.JS WEB FRONTEND DASHBOARD
--------------------------------------------------------------------------------
Command sequence:
cd web-frontend
npm install
npm run dev

Details:
- Open a second terminal window and navigate to the web-frontend folder.
- Run npm install to install Next.js React dependencies.
- Ensure web-frontend/.env.local contains:
  NEXT_PUBLIC_API_URL=http://localhost:5000/api
- Run npm run dev to start Next.js web application.
- Web app will be accessible at: http://localhost:3000.


3. STEP THREE - START THE EXPO CROSS-PLATFORM MOBILE APP
--------------------------------------------------------------------------------
Command sequence:
cd mobile-app
npm install
npx expo start

Details:
- Open a third terminal window and navigate to mobile-app folder.
- Run npm install to install React Native Expo dependencies.
- Run npx expo start to launch the Expo development server.
- Scan the displayed QR code using Expo Go app on iPhone or Android.


4. STEP FOUR - RUN THE NATIVE SWIFTUI IOS APP ON MACOS
--------------------------------------------------------------------------------
Steps for macOS Xcode:
1. Open Xcode on your Mac.
2. Create a new iOS App project named EnterpriseTaskSystemIOS.
3. Import all Swift source files from:
   IOS app/EnterpriseTaskSystemIOS/
4. Open Services/APIManager.swift and set your backend server IP:
   private let baseURL = "http://YOUR_LOCAL_IP:5000/api"
5. Select iPhone 15 Pro or iPhone 16 Pro Simulator in Xcode top bar.
6. Press Cmd + R to build and run the Native SwiftUI iOS App.


5. QUICK SUMMARY OF ALL RUNNING PORTS & SERVICES
--------------------------------------------------------------------------------
- Backend REST API & WebSockets: http://localhost:5000
- Next.js 16 Web Dashboard Portal: http://localhost:3000
- React Native Expo Mobile App: Metro Bundler on Port 8081 / Expo Go
- Native SwiftUI iOS Application: Xcode iOS Simulator / Physical iPhone
